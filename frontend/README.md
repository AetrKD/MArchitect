# MArchitect web console · 웹 콘솔

Manage your Minecraft servers from a browser. For installation, updates, backups, and connection settings, see the [MArchitect user guide](../README.md). The web console is included in the Docker installation; you do not need to install or run it separately.

브라우저에서 마인크래프트 서버를 관리하는 화면입니다. 설치, 업데이트, 백업, 접속 설정은 [MArchitect 사용 안내](../README.md)를 참고하세요. 웹 콘솔은 Docker 설치에 포함되어 있으므로 별도로 설치하거나 실행할 필요가 없습니다.
